# 第一章：基础概念：数字化及时域分析

## 本章导语📖 

数字信号处理的世界，始于两个最基本的概念：**信号**与**系统**。它们就像世界的"数据"与"规则"——我们观察到的现象是信号，而信号如何变化、传递、被处理的规律就是系统。这一章，我们将从零开始，建立对这些基础概念的直觉理解，为后续所有复杂工具打下坚实基础。

## 章节目录📚 

### 1. 信号、系统、序列的基本运算、稳定性、因果性

- **信号**：携带信息的物理量，是我们观察和测量的对象（如声音波形、温度读数、图像像素）
- **系统**：对信号进行变换或处理的装置或算法（如滤波器、放大器、编码器）
- **序列的基本运算**：包括时域变换（移位、反转）和幅值操作（加法、乘法）
- **稳定性**：系统在有界输入下是否只产生有界输出？——现实世界的系统必须稳定才能可靠工作
- **因果性**：系统的输出是否只取决于现在和过去的输入？——物理可实现的系统必须是因果的

### 2. 线性时不变系统（**LTI系统**）

- **线性系统**：必须同时满足两个条件：**可加性**和**齐次性**。
- **时不变系统**：系统的特性不随时间改变——今天和明天对同一输入的响应相同
- **重要性**：绝大多数数字信号处理工具都基于LTI系统的假设，它们有完美的数学描述方法

### 3. 卷积： LTI系统的唯一完整描述

- **核心思想**：描述LTI系统对任意输入的响应——将输入分解为脉冲，分别求响应，再叠加
- **三种视角**：线性时不变系统延迟、倍率、叠加的物理意义、外积矩阵法的代数结构、滑动窗口法的滑动加权平均特性
- **重要性**：信号处理中最基础、最重要的运算，是理解系统如何工作的关键

### 4. 奈奎斯特-香农采样定理与混叠失真

- **核心问题**：如何将连续信号转换为离散数字信号而不丢失信息？
- **奈奎斯特-香农采样定理**：采样频率必须大于信号最高频率的两倍
- **混叠失真现象**：采样不足时高频信号"伪装"成低频信号（见README中的演示）
- **现实意义**：所有数字化过程（音频CD、数字图像、传感器数据）的理论基础

### 5. 差分方程：离散LTI系统的“操作手册”

- **是什么**：描述离散LTI系统输入输出关系的数学方程
- **作用**：用数学语言精确描述系统如何"运行"
- **重要性**：数字滤波器实现、系统仿真、实时信号处理的核心工具
