## 先看一个神奇的“错觉”（Aliasing）

理论之前，先看现象。这是理解**采样定理**为何如此重要的第一步。

我写了一段代码，用 **100 Hz 的采样率** 去采集两个不同的信号：

- **图1**：采集一个 **1 Hz** 和一个 **99 Hz** 的正弦波。
- **图2**：采集一个 **1 Hz** 和一个 **101 Hz** 的正弦波。

<p align="center">
    <img src="images/preface/alias_1hz_99hz.png" width="600" alt="Aliasing Demo Image 1">
</p>

**图1**：99 Hz 的信号（蓝色）被 100 Hz 采样后，看起来完全变成了另一个频率的信号（红色圆点）。你能看出它变成了多少 Hz 吗？

<p align="center">
    <img src="images/preface/alias_1hz_101hz.png" width="600" alt="Aliasing Demo Image 2">
</p>

**图2**：101 Hz 的信号（蓝色）遭遇了同样的命运。采样点（红色圆点）的连线看起来和某个低频信号一模一样。

**思考一下**：为什么 1 Hz、99 Hz、101 Hz 不同的信号，采样后却都变成了 1 Hz？如果采样系统无法区分它们，会导致什么后果？（这就是“失真”）

这个现象就是**混叠失真**。它直指数字信号处理世界的**第一块基石**：我们必须以超过信号最高频率两倍的速率进行采样，才能完整地保留信息。这就是**奈奎斯特-香农采样定理**。


## 我的学习地图：从困惑到清晰

### 数字信号处理核心思想

**如何用计算机（或数字芯片）来处理和分析现实世界中的连续信号（比如声音、图像、电压等）。**

为了防止知识过载，本仓库将整个 DSP 体系重构为以下清晰的递进模块：

#### 一、 基础概念：数字化及时域分析（时域基石）

将模拟信号数字化后进行高效处理的起点。

- **采样定理**：连接模拟与数字世界的桥梁法则，对抗混叠失真。
- **LTI 系统**：线性时不变系统，绝大多数信号处理工具的基石。
- **卷积求和**：从物理响应、代数矩阵、滑动窗口三种视角彻底吃透系统输出。
- **差分方程**：对抗卷积计算瓶颈的工程递推蓝图，一眼看清 FIR 与 IIR 的“血缘”划分。

#### 二、 频域变换：傅里叶变换家族与频谱分析（频域工具）

打破时间轴的束缚，换上“频域的眼睛”看清信号内部的频率成分。

- **空间几何学**：内积、正交与投影，寻找频域的“完美坐标轴”。
- **变换演化史**：理清从 $FS \rightarrow FT \rightarrow DTFT \rightarrow DFS$ 的对偶因果律。
- **离散傅里叶变换 (DFT)**：真正让计算机能够存下、并吞吐有限长数据的工程封装。
- **快速傅里叶变换 (FFT)**：矩阵嵌套分解视角下的算力飞跃，将 $O(N^2)$ 坍缩为 $O(N \log_2 N)$。
- **三大观测陷阱**：工业界频谱分析中最脏的副作用——混叠、泄露与栅栏效应的成因与对策。

#### 三、 复频域桥梁：Z 变换与系统分析（复频域工具）

解开递推方程的“稳定性基因”，从时域递推走向系统的全局掌控。

- **从 DTFT 到 Z 变换**：引入复半径 $r$，将单位圆扩展为整个复平面，解决系统分析问题。
- **收敛域 (ROC)**：决定离散系统因果性与稳定性的代数边界。
- **极零点几何学**：看极点与零点如何像磁铁一样，直观地“拉扯”出系统的频率响应曲线。

#### 四、 一个核心应用：数字滤波器设计（工程落地）

从实际需求出发，设计数字滤波器以精准改造和修饰信号。

- **IIR 滤波器（无限脉冲响应）**：利用模拟滤波器（巴特沃斯/切比雪夫）经验，结构递归，用较低阶数实现陡峭的过渡带，但需警惕相位非线性和稳定性。
- **FIR 滤波器（有限脉冲响应）**：结构非递归，可严格实现线性相位且总是稳定，但需要较高阶数（计算量）才能达到相似性能。

#### 五、 终极目标

无论是时域分析、频域变换还是滤波器设计，我们最终都是为了从信号中提取所需特征信息，完成以下实际任务：

- **滤波**：分离信号中的不同频率成分。
- **降噪**：从受干扰信号中提取有用信息。
- **检测**：识别信号中的特定模式或事件。
- **谱分析**：分析信号的频率组成特性。
- **其他应用**：压缩、增强、合成等信号处理任务。

**别被公式吓倒，去追问它背后的直觉。** 让我们一起，把这座山爬过去。
